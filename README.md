# PAHub 👀
AI-Powered CRM & Marketing Hub

## Project Overview
PAHub is a modular Python application designed to provide free, accessible marketing tools for small businesses.  
It combines a Customer Relationship Management (CRM) system with a dynamic AI Marketing Engine.

## System Architecture
- **Logic Layer**: Built with Python using a modular approach to separate data handling from the user interface.  
- **Data Layer**: Lightweight JSON persistence for CPU efficiency, allowing the app to run on standard hardware without a heavy database.  
- **AI Engine**: Dynamic prompting system that handles user-defined marketing topics.

## Key Features
- Dynamic CRM: Add and track contacts, companies, and deals with automatic timestamping.  
- Universal AI Content: Generates personalized marketing emails for any user-inputted topic.  
- Responsible AI Governance: Ethical disclaimers hard-coded into all AI-generated content.  
- Professional Exports: Export CRM data to CSV for external reporting.
